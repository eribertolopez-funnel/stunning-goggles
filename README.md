# Stunning Goggles Factory

The Stunning Goggles Factory is where Gru's minions get their signature eyewear made. Deep in the lab, rows of tiny assembly stations churn out goggles built to survive whatever chaos a minion gets into — banana spills, chemical splashes, and the occasional explosion included.

Each pair of stunning goggles is custom-fit for minion faces, whether the wearer has one eye or two:

- **Shatterproof lenses** — built to handle lab accidents, kitchen mishaps, and everyday minion mayhem
- **Snug elastic strap** — stays put during running, climbing, and enthusiastic dancing
- **Anti-fog coating** — keeps vision clear even when things get steamy in the villain's lair
- **One-size-fits-most design** — same goggles work for one-eyed and two-eyed minions alike
- **Signature yellow-and-black trim** — so every minion looks the part

Every pair that rolls off the line gets a final inspection before it's handed out, because a minion without properly stunning goggles is a minion waiting for an accident to happen.
